# Data options: every dataset the Veritas brief suggests

Checked Sat Nov 14, 2026, from official dataset pages, official docs and API metadata. Research only: nothing was downloaded and no code was run, so "loads" means "the official page says it loads this way", not "I tested it in Colab". Anything I could not confirm is marked **not verified**. This file does not recommend a track or an idea.

Source of the list: `docs/challenge.md` (the Veritas Project Briefs PDF).

## Summary

- **Load with no sign-in, no key, no terms click (documented):** PneumoniaMNIST, UCI Heart Disease, SMS Spam (UCI file, and the Hugging Face mirror), Statlog German Credit, WHO GHO API (no key mentioned), Our World in Data CSVs, NASA POWER, Open-Meteo (weather and air quality), EuroSAT, Tatoeba, FLEURS.
- **Cannot be run by a judge without an account or token:** FLORES+ (Hugging Face login plus terms), Mozilla Common Voice (Mozilla Data Collective API key plus terms in the web UI, and it has left Hugging Face), OpenAQ API (free key from sign-up), Kaggle Daily News for Stock Market Prediction (Kaggle only; the only Hugging Face copy I found is gated).
- **Kaggle is a coin flip:** the Chest X-Ray and Credit Card Fraud datasets live on Kaggle, which normally wants a login. Both have public mirrors that need no account (Hugging Face `hf-vision/chest-xray-pneumonia`; a Google-hosted CSV URL and OpenML for fraud). `kagglehub`'s README says sign-in is only needed for "public resources requiring user consent or private resources", so it may work keyless, but I did not verify that for these datasets. The team can test it in a fresh Colab with no Kaggle secrets.
- **Three surprises in the brief:**
  - Common Voice is no longer on Hugging Face (since October 2025).
  - `fetch_ucirepo(id=45)` should return only the 303 Cleveland patients, so the "other hospitals" idea needs the raw files in the UCI zip.
  - Open-Meteo's pricing page and its API docs disagree about whether historical data is free (see its row).
- **Biggest data-quality catches:** Chest X-Ray Kaggle has a 16-image validation split. Credit Card Fraud is 0.17% fraud with anonymized PCA features. SMS Spam is old and not date-sorted. German Credit is from 1994 and has age and sex baked into columns. Daily News stops in July 2016 and is CC BY-NC-SA.

## Best fits for a beginner team on free Colab with no sign-in

Each of these has a documented no-sign-in route, a small download, labels you can score, and a license that allows use with a credit line. The order is not a ranking, and none of them is a track or idea recommendation.

1. **SMS Spam Collection** (Hugging Face `ucirvine/sms_spam` or the UCI zip). A few hundred KB, ready labels, one line to load, CC BY 4.0 on UCI. Catch: the license says "unknown" on the Hugging Face card, so cite the UCI page.
2. **PneumoniaMNIST** (`pip install medmnist`). 4.2 MB at 28px, already split train/val/test, CC BY 4.0. The 28px images are small, so a plain CPU model runs in minutes. Catch: tiny images.
3. **UCI Heart Disease** (`fetch_ucirepo(id=45)`). 303 rows, CC BY 4.0, almost balanced, trains in seconds. Catch: the library call likely returns Cleveland only, so the "other hospitals" test needs the raw files in the zip.
4. **Statlog German Credit** (`fetch_ucirepo(id=144)`). 1,000 rows, CC BY 4.0, has an age column and a published cost matrix. Catch: 1994 data, small, and sensitive columns (age, sex).
5. **NASA POWER, with Open-Meteo as a second source** (REST calls, no key). NASA says no authentication and CC BY 4.0; daily data from 1981, so there is plenty of history for an unshuffled time split. Catch: you build the target yourself, and Open-Meteo's historical access conflicts between its pricing page and docs, so test it in a fresh Colab.
6. **Tatoeba language ID** (plain `downloads.tatoeba.org` URLs, per-language files of about 10 MB). No sign-in, millions of labeled sentences, easy to balance. Catch: the export changes every Saturday, so save the download date, and some languages dominate the counts.

Also workable, but with more setup: **EuroSAT** (no sign-in and MIT license, but needs a GPU and your own split) and **FLEURS** (no sign-in, but about 1 GB per language and needs a GPU).

## Not ready for a judge's fresh Colab

- **FLORES+:** HF login and terms. **Common Voice:** MDC key and terms, and it left Hugging Face. **OpenAQ API:** key from sign-up. **Daily News:** Kaggle only (CC BY-NC-SA).
- **Kaggle Chest X-Ray and Credit Card Fraud:** use the no-account mirrors noted in the table, or test `kagglehub` keyless first.

## What I could not verify

- Whether `kagglehub` downloads work without any credentials for the three Kaggle datasets.
- That the TensorFlow-hosted fraud CSV and the OpenML file are still live today (documented only).
- Live Open-Meteo access to the historical and air quality APIs without a key.
- WHO GHO license, and whether the GHO API returns JSON.
- NASA POWER units for `ALLSKY_SFC_SW_DWN`, newest-day latency, and rate limits.
- Exact per-class counts for PneumoniaMNIST and EuroSAT, and whether any of the image datasets split by patient or tile.
- The Common Voice MDC pages (they did not render), including whether an account is needed just to view or download, and accent metadata.
- Whether Open-Meteo's and NASA's APIs behave the same from Colab's shared IP addresses as from my reading of the docs.
