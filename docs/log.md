## Known failures and limits

- The picker reads endings only: on the practice rows 8 of 15 picks have the right endings but the wrong meaning (The Serbian speaker's check). See the Phase 4 entry.
- Present-tense options can't show the listener's gender, and repair can't change the tense (t22).
- Fixed in Phase 4b: "Doći ću" (future tense) is no longer read as a casual command (The Serbian speaker's Q2). New limit from that rule: casual commands ending in -ti (*vrati*, *plati*, *pusti*) now read as infinitives.
- Casual *te* ("you") only counts on hand-marked rows (t39) or in *molim te*; new sentences in the demo won't get it.
- NLLB on Apple's GPU (`mps`) gave broken output, so local runs use the CPU.
- Test rows (Phase 5): NLLB can break into a repeating answer even on the CPU (t30, *Ne, ne, ne…*): no option fits and the picker can only flag it.
- Control rows are not checked at all, so NLLB's top answer goes through even when it invents a speaker or a non-word (t56).
- `to_latin()` misses the Macedonian letter ѓ (t21 *ѓubre*). Found on the test rows, not fixed so the test numbers stay as scored.
- Workplace words NLLB doesn't know: forklift came out as non-words on both practice (t06) and test (t32).
