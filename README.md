Our team's entry for the Veritas AI International High School Hackathon (Nov 14-15, 2026). The track and idea are picked on the team's first call; see [docs/kickoff-brief.md](docs/kickoff-brief.md).

## Open the notebook in Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/proelium27/veritas-ai-hackathon/blob/main/notebook/model.ipynb)

While the repo is private, the button only works if you've connected Colab to GitHub and allowed private repositories (Colab: File → Open notebook → GitHub). Then click **Runtime → Run all**. It needs no sign-in, keys or uploads.
